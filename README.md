# Cat Invaders

Space invaders, but it is a cat defending against rats


Hi! This is a project for Hack Club Terra in which I utilized the ncurses library as I havent in a long time. Because of that, expect bugs or not the best of optimization, if you have any tips: contact me!

Also if the game imidiatelly exits, resize your terminal to be bigger!

# How to play?

1. Download the .exe or the .zip and run cat-invaders.exe
2. Disregard the windows popup as the exe is unsigned ()

3. If you are on linux: install the ncurses library (no clue how to do this as I do not use linux).

# Symbols:

- ~o> - mice
- ~0> - mice squared (2 hp)
- @ - bombs
- hastags - powerups
- =^. .^= - cat
- ^ - bullets
- red hastags - EVIL powerups
- big alien thingy - boss

# Tutorial?

- Shoot the mice before they reach you
- A boss wave appears every so often
- By shooting mice build up score to spend in the shop between the waves to make your cat more powerful
- To find the secret cheat codes look into the source code of the game :p (Will leave a mark showing that you are evil though)
